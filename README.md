# extension
DSA Hint Assistant is a lightweight, productivity-focused Chrome Extension engineered for software engineers, competitive programmers, and students looking to optimize their Data Structures and Algorithms (DSA) preparation.  Instead of jumping straight to a solution or reading verbose editorials when stuck, the extension acts as an interactive mentor directly within the browser tab. By extracting runtime page context from active problem screens via a dynamic content script, it interfaces securely with the Gemini 2.0 Flash API to generate intelligent, context-aware hints tailored precisely to the user's current progression.
